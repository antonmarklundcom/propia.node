## Decisions

- Restyled the shared `.home-how__num` / `.home-pro__button` classes with
  `.directory-home` ancestor scoping rather than new component branches —
  colour/type still come from tokens, the scoping is CSS specificity, not a
  `vertical.key` conditional in a shared component (the prompt's hard limit).
- `.home-values` (como-elegimos) needed no restyle: it already renders as
  plain hairline-top columns on the cream background with the existing
  tokens.
- Kept `DirectoryHome.tsx`'s JSX and section order untouched — every visual
  change routes through tokens or the new CSS block, so the component itself
  did not need editing beyond what already read the (now-changed) dictionary
  keys.
- `formNext`/`formNext2` are plain `type="button"` handlers, not native
  submits — only step 3's button is `type="submit"`, so the existing
  `onSubmit`/`fetch` logic runs exactly once, at the end, as before.
