# P2 — hub hero photos (venta, alquiler)

## What landed

- `.hub-hero` now carries `data-op={op}` in `app/[operacion]/page.tsx`. P1 had
  not added it on `origin/main` when this phase branched, so P2 owns it.
- A `/* == P2 == */` block at the end of `app/globals.css` wires
  `/img/hub-venta.webp` and `/img/hub-alquiler.webp` as hero backgrounds on
  `[data-op="venta"]` and `[data-op^="alquiler"]` (the prefix selector is how
  the `alquiler_temporal` hub reuses the alquiler photo, per decision 2).
- Three background layers: translucent dark overlay, photo, then an **opaque**
  copy of the hub's original flat gradient. The third layer is why the rule is
  harmless with the files absent — a missing `url()` paints nothing and the
  hero falls back to its pre-P2 look, not to a transparent band.
- Contrast read from the alpha, not by eye: worst case is a pure-white photo
  pixel under the lightest overlay stop (0.72) on the lightest door primary in
  the token set (`#182830`). Composited that is `#58646A`; `#fff` on it is
  6.0:1, over AA 4.5:1. Every other door primary is darker.

## Known issues

- **The two WebP files are not in the repo, and no credits were spent.** This
  environment answers `CONNECT 403` for every external host (checked twice,
  including `*.cloudfront.net` and `example.com`), which is the known failure
  named in the `higgsfield-image-pipeline` skill, Rule 2. With no download path
  the skill's Rule 0 verdict is to stop *before* generating rather than buy a
  set nobody can localize, and this prompt's decision 4 says the same.
- **Manual step, once, then any later session finishes this in minutes:**
  claude.ai/code → environment selector → edit the environment → Network
  access: Custom → Allowed domains `*.cloudfront.net` → tick the package
  managers box → save, and make it the default environment. Then a session
  generates the two prompts below with `nano_banana_pro` at `2k`, 16:9
  (4 credits total), converts with webimg to ≤ 220 KB at 1920px wide, drops
  them at `public/img/hub-venta.webp` / `public/img/hub-alquiler.webp` and
  changes nothing else — the CSS is already correct.
